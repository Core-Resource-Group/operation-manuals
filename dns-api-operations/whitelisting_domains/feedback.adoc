= DNS domain whitelisting template feedback

.Notes
* "GMS" in templates' Classification & Risk Assessment refers to "Gross Merchant Sales". "GMS Impact" is anything that might directory _or indirectly_ impact customer-facing services, causing outages and/or service disruption.

.General Feedback
* TASC Reviewers *MUST* be granted access to the operational codebases for review. Operational code is expected to live on-premise, generally on the company's standard BitBucket service. Not all Reviewers have GHC or even GHE access.
* Anywhere commands are being run and checks are recording correct behaviour of the system (e.g. Step 4), evidence *MUST* be captured, which MUST be recorded on the CM ticket for the Operation (redacted if required for confidentiality). Details of what evidence to capture needs to be provided in the relevant steps, along with clear examples. For text-commands, copy/paste of text output is acceptable. For UI usage, screenshosts are acceptable.
